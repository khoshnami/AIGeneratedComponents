DigForm

شرح
---
DigForm یک کامپوننت نمونهٔ فرم ثبت‌نام است که با استفاده از react-hook-form پیاده‌سازی شده و الگوهای کلیدی از فرمِ دیگ (Dig) را به‌صورت ساده‌شده پیاده می‌کند. این فرم شامل فیلدهای نام و نام‌خانوادگی، ایمیل و رمز عبور است، اعتبارسنجی سمت کلاینت را انجام می‌دهد و نمونه‌ای از مدیریت خطاهای سمت سرور را هم نشان می‌دهد (اگر ایمیل برابر "error@example.com" باشد، خطای سرور شبیه‌سازی می‌شود).

این کامپوننت مناسب است وقتی می‌خواهید یک فرم قابل استفاده، ساده و قابل فهم با حداقل وابستگی‌ها داشته باشید و همچنین رفتار حذف خطاهای سرور هنگام ویرایش فیلد را نمایش دهد.

کدام کامپوننت انتخاب شد و چرا
---
کامپوننت پایهٔ فرم از پیاده‌سازی "form" در کتابخانهٔ دیگ الهام گرفته شده و به‌صورت ساده‌شده بازسازی شد تا مستقیم در یک فایل مستقل قابل استفاده باشد. دلیل انتخاب این الگو:
- رفتار مفیدِ اتصال react-hook-form به اجزای فرم (FormProvider, Controller) را حفظ می‌کند.
- مدیریت خطاهای سمت سرور را دارد (خطا با type: "server" ثبت می‌شود و هنگام تغییر فیلد پاک می‌شود).
- مستقل از اجزای داخلی پروژه است و با حداقل پیش‌نیاز (فقط react و react-hook-form) کار می‌کند.

آیکون انتخاب شده و چرا
---
برای فیلد رمزِ عبور از آیکونِ "Eye" (سبک Linear) استفاده شد تا قابلیت نمایش/مخفی‌سازی رمز را نشان دهد. این آیکون ساده، خوانا و رایج برای نشان‌دادن حالت دیدن رمز است و در نسخهٔ JSX درون فایل قرار گرفته تا نیازی به بارگذاری جداگانهٔ فایل svg یا کتابخانهٔ آیکون نباشد.

نحوه استفاده
---
1. مطمئن شوید react و react-hook-form در پروژه نصب است:

   npm install react react-hook-form

2. فایل را در پروژه‌تان (مثلاً DigForm.tsx یا DigForm.jsx) ذخیره کنید.
3. کامپوننت را ایمپورت و استفاده کنید:

   import DigForm from './DigForm';

   function Page() {
     return <DigForm />;
   }

نکات و گسترش
---
- این پیاده‌سازی برای نمایش کارکرد اصلی فرم بهینه شده است؛ می‌توانید آن را به‌راحتی با استایل‌دهی دلخواه، کامپوننت‌های UI کتابخانه‌ای یا validation resolver گسترش دهید.
- بخش serverErrors نشان می‌دهد چگونه می‌توان خطاهای بازگشتی از سرور را به خطاهای فرم مپ کرد تا UX بهتری فراهم شود (خطای سرور هنگام ویرایش فیلد پاک می‌شود).
