LoginForm

خلاصه
---
LoginForm یک فرم ورود (JavaScript) ساده و کامل است که با react-hook-form پیاده‌سازی شده و تمام آیکون‌های موردنیاز داخلِ همان فایل قرار گرفته‌اند (SVGهای سبک Linear در قالب کامپوننت‌های React). این فرم شامل فیلد ایمیل/نام‌کاربری، رمز عبور، گزینه «مرا به خاطر بسپار»، نمایش/مخفی‌سازی رمز و دکمه‌های نمونهٔ ورود اجتماعی است.

ویژگی‌ها
---
- خروجی جاوااسکریپت (بدون TypeScript).  
- اعتبارسنجی کلاینت با react-hook-form.  
- مدیریت خطاهای سمت سرور: اگر سرور خطایی برگرداند (در این نمونه با مقدارِ مشخص شبیه‌سازی می‌شود)، خطا به‌صورت type: "server" به فرم اضافه می‌شود و هنگام ویرایش همان فیلد پاک می‌گردد.  
- آیکون‌ها: User, Email, Lock (lock-square), Eye همه به‌صورت JSX در فایل قرار دارند — نیازی به کتابخانهٔ خارجی نیست.

آیکون‌ها و دلیل انتخاب
---
- EmailIcon: برای فیلد ایمیل/شناسه، چون معنی واضحِ ایمیل/شناسه را منتقل می‌کند.  
- LockIcon: به‌عنوان نماد امنیت برای فیلد رمز عبور (از lock-square استفاده شد).  
- EyeIcon: برای نمایش/مخفی‌سازی رمز؛ رایج و قابل فهم برای کاربران.  
- UserIcon: برای نشان‌دادن ورود با حساب یا در بخش ورود اجتماعی.

کامپوننت انتخاب‌شده و دلیل
---
نام کامپوننت: LoginForm

این کامپوننت یک فرم ورود ساده و قابل توسعه است که الگوهای معمول فرم (validation, server-error mapping, accessibility basics) را پیاده‌سازی می‌کند و به‌خوبی در صفحات ورود اپلیکیشن قرار می‌گیرد.

مسئلهٔ ارسال نام پروژه برای آمار دیگ
---
شما خواستید اسم پروژه "login" باشد؛ با این حال خواستید اطلاعات آماری دیگ ارسال نشود. در نتیجه نام پروژه فقط به‌عنوان یک ثابت محلی داخل فایل قرار گرفته و به هیچ سرویسی ارسال نمی‌شود (پیکربندی ارسال آمار انجام نشد).

نحوه استفاده
---
1. وابستگی‌ها را نصب کنید:

   npm install react react-dom react-hook-form

2. فایل را در پروژه‌تان ذخیره کنید (مثلاً LoginForm.jsx) و سپس:

   import LoginForm from './LoginForm';

   function Page() {
     return <LoginForm />;
   }

گسترش
---
- می‌توانید استایل‌ها را به CSS/utility framework موردنظرتان منتقل کنید.  
- برای احراز هویت واقعی، در onSubmit درخواست به سرور ارسال کنید و خطاها را به شکلِ serverErrors به فرم وارد کنید تا UX مشابه نمونهٔ این کامپوننت داشته باشید.
